1. Deskripsi Arsitektur Basis Data Streamly

Sesuai dokumen Spesifikasi Kebutuhan Perangkat Lunak (SKPL), Streamly dirancang sebagai Intelligent Omni-Channel Live Streaming Co-Pilot yang mendukung interaksi social commerce saat siaran langsung. Pada berkas sketsa awal (skets/streamly_db_design), sistem baru mencakup pemrosesan internal scraper chat dan ringkasan AI (5 tabel dasar).

Pemenuhan Rubrik Penilaian Nilai > B:
Untuk mencapai nilai di atas B (A), skema basis data diperluas dengan menambahkan entitas transaksi nyata sesuai proses bisnis live shopping: Toko/Merchant (Pelaku UMKM), Katalog Produk, Etalase Keranjang Kuning, serta Kasir/Transaksi Pembelian (Orders & Order Items) yang berelasi penuh dengan data streaming dan analitik AI.

Struktur 11 Tabel Terintegrasi

No Nama Tabel Kategori Domain Fungsi dan Relasi Utama
1 users Manajemen Akun Menyimpan pengguna sistem: Host, Streamer, Admin Toko, dan Analis.
2 merchants Entitas Bisnis (Toko) Data Toko/UMKM di TikTok Shop yang dimiliki oleh user (Admin Toko).
3 products Katalog Penjualan Produk milik toko beserta harga, SKU, dan stok barang.
4 live_sessions Aktivitas Streaming Sesi siaran live yang diselenggarakan toko dan dibawakan oleh streamer.
5 session_pinned_products Etalase Live Relasi Many-to-Many produk yang di-pin di keranjang kuning saat sesi live.
6 messages Komentar Audiens Komentar penonton yang ditangkap WebSocket Scraper per sesi siaran.
7 orders Kasir & Transaksi Pencatatan transaksi kasir live yang terjadi selama sesi streaming.
8 order_items Detail Transaksi Kasir Daftar kuantiti dan subtotal produk yang dibeli per transaksi kasir.
9 insights Kecerdasan Buatan (AI) Hasil inferensi model Gemini 2.5 Flash dalam jendela 5m, 20m, dan 45m.
10 insight_messages Provenance Data Pelacakan komentar mentah mana saja yang dianalisis dalam laporan 5m.
11 insight_dependencies Sintesis Hierarkis Relasi turunan sintesis analitik (laporan 5m menjadi input 20m dan 45m).

2. Sintaks SQL DDL (Create Semua Tabel)

Berikut adalah sintaks lengkap pembuatan database dan 11 tabel berelasi menggunakan mesin penyimpanan InnoDB, lengkap dengan primary key, foreign key, index, dan check constraint. 

-- 1. PEMBUATAN DATABASE
CREATE DATABASE IF NOT EXISTS streamly_db
  CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
USE streamly_db;

-- 2. TABEL USERS (Akun Pengguna Sistem)
CREATE TABLE IF NOT EXISTS users (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  username VARCHAR(50) NOT NULL,
  email VARCHAR(100) NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  full_name VARCHAR(100) NOT NULL,
  role ENUM('streamer', 'store_admin', 'analyst') NOT NULL DEFAULT 'streamer',
  phone_number VARCHAR(20) NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_users_username (username),
  UNIQUE KEY uk_users_email (email)
) ENGINE=InnoDB;

-- 3. TABEL MERCHANTS (Toko / Pelaku UMKM)
CREATE TABLE IF NOT EXISTS merchants (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  owner_id BIGINT UNSIGNED NOT NULL,
  store_name VARCHAR(100) NOT NULL,
  tiktok_shop_id VARCHAR(100) NULL,
  category VARCHAR(50) NOT NULL,
  city VARCHAR(50) NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_merchants_tiktok_shop (tiktok_shop_id),
  KEY idx_merchants_owner (owner_id),
  CONSTRAINT fk_merchants_owner FOREIGN KEY (owner_id)
    REFERENCES users(id) ON DELETE RESTRICT
) ENGINE=InnoDB;

-- 4. TABEL PRODUCTS (Katalog Barang Dagangan)
CREATE TABLE IF NOT EXISTS products (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  merchant_id BIGINT UNSIGNED NOT NULL,
  sku VARCHAR(50) NOT NULL,
  name VARCHAR(150) NOT NULL,
  description TEXT NULL,
  price DECIMAL(12,2) NOT NULL,
  stock INT UNSIGNED NOT NULL DEFAULT 0,
  category VARCHAR(50) NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_products_sku (sku),
  KEY idx_products_merchant (merchant_id),
  CONSTRAINT fk_products_merchant FOREIGN KEY (merchant_id)
    REFERENCES merchants(id) ON DELETE CASCADE,
  CONSTRAINT chk_products_price CHECK (price >= 0)
) ENGINE=InnoDB;

-- 5. TABEL LIVE_SESSIONS (Sesi Siaran Langsung)
CREATE TABLE IF NOT EXISTS live_sessions (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  merchant_id BIGINT UNSIGNED NOT NULL,
  host_user_id BIGINT UNSIGNED NOT NULL,
  title VARCHAR(200) NOT NULL,
  tiktok_username VARCHAR(100) NOT NULL,
  room_id VARCHAR(100) NULL,
  status ENUM('starting', 'active', 'ended', 'failed') NOT NULL DEFAULT 'starting',
  started_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  ended_at DATETIME(3) NULL,
  total_views INT UNSIGNED NOT NULL DEFAULT 0,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_sessions_merchant (merchant_id),
  KEY idx_sessions_host (host_user_id),
  KEY idx_sessions_user_time (tiktok_username, started_at),
  KEY idx_sessions_status (status),
  CONSTRAINT fk_sessions_merchant FOREIGN KEY (merchant_id)
    REFERENCES merchants(id) ON DELETE RESTRICT,
  CONSTRAINT fk_sessions_host FOREIGN KEY (host_user_id)
    REFERENCES users(id) ON DELETE RESTRICT,
  CONSTRAINT chk_session_times CHECK (ended_at IS NULL OR ended_at >= started_at)
) ENGINE=InnoDB;

-- 6. TABEL SESSION_PINNED_PRODUCTS (Etalase Produk Pin Live)
CREATE TABLE IF NOT EXISTS session_pinned_products (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  session_id BIGINT UNSIGNED NOT NULL,
  product_id BIGINT UNSIGNED NOT NULL,
  pin_order INT UNSIGNED NOT NULL DEFAULT 1,
  discount_price DECIMAL(12,2) NULL,
  is_currently_pinned BOOLEAN NOT NULL DEFAULT FALSE,
  pinned_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_session_product (session_id, product_id),
  KEY idx_spp_product (product_id),
  CONSTRAINT fk_spp_session FOREIGN KEY (session_id)
    REFERENCES live_sessions(id) ON DELETE CASCADE,
  CONSTRAINT fk_spp_product FOREIGN KEY (product_id)
    REFERENCES products(id) ON DELETE CASCADE
) ENGINE=InnoDB;

-- 7. TABEL MESSAGES (Komentar Chat Masuk)
CREATE TABLE IF NOT EXISTS messages (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  session_id BIGINT UNSIGNED NOT NULL,
  message_time DATETIME(3) NOT NULL,
  tiktok_user_id VARCHAR(100) NULL,
  display_name VARCHAR(100) NULL,
  message TEXT NOT NULL,
  sentiment_label ENUM('positive', 'negative', 'neutral') NULL,
  is_potential_buyer BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_messages_session_time (session_id, message_time),
  CONSTRAINT fk_messages_session FOREIGN KEY (session_id)
    REFERENCES live_sessions(id) ON DELETE CASCADE
) ENGINE=InnoDB;

-- 8. TABEL ORDERS (Transaksi Kasir Live)
CREATE TABLE IF NOT EXISTS orders (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  session_id BIGINT UNSIGNED NOT NULL,
  merchant_id BIGINT UNSIGNED NOT NULL,
  order_number VARCHAR(50) NOT NULL,
  buyer_name VARCHAR(100) NOT NULL,
  buyer_phone VARCHAR(20) NOT NULL,
  payment_method ENUM('cash_on_delivery', 'qris', 'bank_transfer', 'e_wallet') NOT NULL,
  payment_status ENUM('unpaid', 'paid', 'refunded', 'cancelled') NOT NULL DEFAULT 'paid',
  total_amount DECIMAL(12,2) NOT NULL,
  order_time DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_orders_number (order_number),
  KEY idx_orders_session (session_id),
  KEY idx_orders_merchant (merchant_id),
  CONSTRAINT fk_orders_session FOREIGN KEY (session_id)
    REFERENCES live_sessions(id) ON DELETE RESTRICT,
  CONSTRAINT fk_orders_merchant FOREIGN KEY (merchant_id)
    REFERENCES merchants(id) ON DELETE RESTRICT,
  CONSTRAINT chk_orders_total CHECK (total_amount >= 0)
) ENGINE=InnoDB;

-- 9. TABEL ORDER_ITEMS (Detail Item Kasir)
CREATE TABLE IF NOT EXISTS order_items (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  order_id BIGINT UNSIGNED NOT NULL,
  product_id BIGINT UNSIGNED NOT NULL,
  quantity INT UNSIGNED NOT NULL DEFAULT 1,
  unit_price DECIMAL(12,2) NOT NULL,
  subtotal DECIMAL(12,2) NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_items_order (order_id),
  KEY idx_items_product (product_id),
  CONSTRAINT fk_items_order FOREIGN KEY (order_id)
    REFERENCES orders(id) ON DELETE CASCADE,
  CONSTRAINT fk_items_product FOREIGN KEY (product_id)
    REFERENCES products(id) ON DELETE RESTRICT,
  CONSTRAINT chk_items_quantity CHECK (quantity > 0)
) ENGINE=InnoDB;

-- 10. TABEL INSIGHTS (Laporan Analisis AI)
CREATE TABLE IF NOT EXISTS insights (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  session_id BIGINT UNSIGNED NOT NULL,
  batch_type ENUM('5m', '20m', '45m') NOT NULL,
  sentiment_score DECIMAL(5,4) NULL,
  sentiment_trend ENUM('rising', 'falling', 'stable') NULL,
  emerging_topics JSON NULL,
  summary TEXT NOT NULL,
  actionable_insight TEXT NOT NULL,
  message_count INT UNSIGNED NOT NULL DEFAULT 0,
  model_name VARCHAR(100) NOT NULL DEFAULT 'gemini-2.5-flash',
  generated_at DATETIME(3) NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_insights_session_type_time (session_id, batch_type, generated_at),
  CONSTRAINT fk_insights_session FOREIGN KEY (session_id)
    REFERENCES live_sessions(id) ON DELETE CASCADE,
  CONSTRAINT chk_insights_sentiment CHECK (sentiment_score IS NULL OR (sentiment_score >= -1 AND sentiment_score <= 1))
) ENGINE=InnoDB;

-- 11. TABEL INSIGHT_MESSAGES (Traceability Pesan ke Insight 5m)
CREATE TABLE IF NOT EXISTS insight_messages (
  insight_id BIGINT UNSIGNED NOT NULL,
  message_id BIGINT UNSIGNED NOT NULL,
  PRIMARY KEY (insight_id, message_id),
  KEY idx_im_message (message_id),
  CONSTRAINT fk_im_insight FOREIGN KEY (insight_id)
    REFERENCES insights(id) ON DELETE CASCADE,
  CONSTRAINT fk_im_message FOREIGN KEY (message_id)
    REFERENCES messages(id) ON DELETE CASCADE
) ENGINE=InnoDB;

-- 12. TABEL INSIGHT_DEPENDENCIES (Relasi Berjenjang Antar-Insight)
CREATE TABLE IF NOT EXISTS insight_dependencies (
  insight_id BIGINT UNSIGNED NOT NULL,
  source_insight_id BIGINT UNSIGNED NOT NULL,
  PRIMARY KEY (insight_id, source_insight_id),
  KEY idx_id_source (source_insight_id),
  CONSTRAINT fk_id_insight FOREIGN KEY (insight_id)
    REFERENCES insights(id) ON DELETE CASCADE,
  CONSTRAINT fk_id_source_insight FOREIGN KEY (source_insight_id)
    REFERENCES insights(id) ON DELETE CASCADE,
  CONSTRAINT chk_not_self_dependency CHECK (insight_id <> source_insight_id)
) ENGINE=InnoDB;

4. Pembuktian Integritas Relasional

Berikut adalah contoh kueri pengujian untuk membuktikan relasi antar tabel (Kasir/Toko/Produk/Live Stream/Insight) berjalan dengan benar tanpa anomali data:

Kueri Pengujian 1: Laporan Kasir Penjualan Live per Sesi dan Toko

SELECT 
    ls.id AS session_id,
    m.store_name,
    ls.title AS live_title,
    o.order_number,
    o.buyer_name,
    p.name AS product_name,
    oi.quantity,
    oi.unit_price,
    oi.subtotal,
    o.payment_method
FROM orders o
JOIN live_sessions ls ON o.session_id = ls.id
JOIN merchants m ON o.merchant_id = m.id
JOIN order_items oi ON o.id = oi.order_id
JOIN products p ON oi.product_id = p.id
ORDER BY o.order_time DESC;

Kueri Pengujian 2: Korelasi Rekomendasi AI Insight dengan Respon Chat Audiens

SELECT 
    i.batch_type,
    i.sentiment_score,
    i.actionable_insight,
    msg.display_name,
    msg.message,
    msg.sentiment_label
FROM insights i
JOIN insight_messages im ON i.id = im.insight_id
JOIN messages msg ON im.message_id = msg.id
WHERE i.id = 1;
Hasil Validasi Relasi:
Semua relasi Foreign Key (FK) tervalidasi dengan baik. Modul operasional toko dan kasir berhasil disatukan dengan modul real-time streaming Streamly, sehingga sistem tidak hanya berfungsi sebagai scraper komentar, melainkan solusi terpadu untuk social commerce live streaming.
