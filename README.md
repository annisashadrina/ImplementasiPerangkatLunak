## 🚀 Proyek: Streamly
### *Intelligent Omni-Channel Live Streaming Co-Pilot*

**Streamly** adalah platform berbasis web yang dioptimalkan untuk memfasilitasi aktivitas *social commerce* melalui *live streaming*. Sistem ini berfungsi sebagai asisten interaktif cerdas (*co-pilot*) yang dirancang untuk membantu *livestreamer* mengelola ribuan komentar audiens secara *real-time* menggunakan analisis data dan kecerdasan buatan (AI).

## 📄 Ringkasan Dokumen SKPL (Week 03)
Dokumen **SKPL (Spesifikasi Kebutuhan Perangkat Lunak)** yang telah disusun mencakup:
- **Pendahuluan:** Tujuan, ruang lingkup produk, definisi, singkatan, dan referensi sistem.
- **Deskripsi Global:** *Statement of objective*, perspektif produk, profil kelas pengguna (*Livestreamer* & Admin), lingkungan operasi, batasan, serta dependensi.
- **Deskripsi Rinci Kebutuhan:**
  - Kebutuhan Fungsional (manajemen streaming multi-kanal, filtering & klasifikasi komentar, asistensi AI real-time, analitik engagement).
  - Kebutuhan Non-Fungsional (keandalan sistem real-time, latensi rendah, keamanan data).
  - Pemodelan Analisis: *Use Case Diagram* & *Class Diagram*.
- **Kebutuhan Antarmuka & Modul Cerdas:** Spesifikasi UI/UX, integrasi API multi-platform live streaming, dan sistem klasifikasi pesan.
